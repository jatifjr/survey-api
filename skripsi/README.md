## Suggested Thesis Direction

Implement and evaluate a lightweight DevOps workflow for a FastAPI service on a VM, then measure deployment reliability and recovery improvements using objective metrics.

## Locked Scope Summary

- Main focus: deployment reliability and recovery consistency
- Main intervention: quality gate, image delivery, deployment verification, rollback workflow
- Main evidence: baseline vs intervention KPI comparison
- Supporting scope only: Terraform/infrastructure provisioning
