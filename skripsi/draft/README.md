# Draft Skripsi

Folder ini berisi draft penulisan per BAB.
Seluruh file pada folder ini diposisikan sebagai **area penulisan utama**, sedangkan folder `skripsi/` di tingkat atas diposisikan sebagai **catatan referensi dan bahan kerja**.

## Isi

- `01-pendahuluan.md`
- `02-tinjauan-pustaka.md`
- `03-metodologi-penelitian.md`
- `04-analisis-kondisi-awal.md`
- `05-perancangan-workflow-devops.md`
- `06-implementasi.md`
- `07-pengujian-dan-evaluasi.md`
- `08-kesimpulan-dan-saran.md`

## Cara Pakai

- Gunakan file per BAB sebagai tempat menulis langsung.
- Bagian yang sudah cukup jelas sudah diisi dengan draft awal.
- Bagian yang masih menunggu data nyata disiapkan dalam bentuk outline, deskripsi singkat, atau TODO.
- Pertahankan struktur yang konsisten pada setiap file: `Status`, isi BAB, lalu `TODO Lanjutan`.

## Saran Urutan Pengerjaan

1. Rapikan `01-pendahuluan.md`
2. Kumpulkan referensi untuk `02-tinjauan-pustaka.md`
3. Finalkan `03-metodologi-penelitian.md`
4. Isi baseline nyata pada `04-analisis-kondisi-awal.md`
5. Sesuaikan `05-perancangan-workflow-devops.md` dan `06-implementasi.md` dengan deployment flow final
6. Lengkapi `07-pengujian-dan-evaluasi.md` setelah eksperimen selesai
7. Tulis `08-kesimpulan-dan-saran.md` paling akhir
